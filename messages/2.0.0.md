Breaking changes:

- The key used to override LSP-terraform settings in project settings has changed from `terraform` to `LSP-terraform`.
  If you use project-specific overrides for LSP-terraform, you have to rename the key for them to apply:

  Before:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "terraform": {
                  // ...
              }
          }
      }
  }
  ```

  After:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "LSP-terraform": {
                  // ...
              }
          }
      }
  }
  ```
